# Converting Old Wood Windows to Crank-Operated Casement Windows

This document provides a guide for the advanced DIY project of converting an old, non-crank-operated wood window into a modern, crank-operated casement window with a fixed screen, while retaining the original full wood window.

**Disclaimer:** This is a complex woodworking project that requires a high level of skill. For valuable or historic windows, it is strongly recommended to consult with a professional window restoration specialist.

## Introduction

The goal of this project is to add modern casement functionality (a crank operator and a fixed screen) to an existing traditional wood window. This allows you to maintain the aesthetic of the original window while gaining the convenience and functionality of a modern window.

## Recommended Hardware

For this project, we recommend a **split-arm operator** and **stainless steel four-bar hinges**. This combination is common, well-documented, and suitable for retrofitting on wood windows.

- **Casement Operator:** A split-arm operator is a good choice for this type of project. Look for a high-quality operator from a reputable brand like **Truth Hardware** or **AmesburyTruth**. You will need to select an operator that is rated for the size and weight of your window.
- **Hinges:** Stainless steel **four-bar hinges** (also known as friction hinges) are ideal. They are durable, provide smooth operation, and can hold the window open in any position. Again, ensure the hinges are rated for the weight of your window.
- **Locking Mechanism:** A new lock for the casement window.

You can find these parts at specialty window hardware suppliers online, such as **Window Hardware Direct** or **All About Doors and Windows**.

## Hardware and Materials

- **Casement Operator:** The crank mechanism. Selection is critical and depends on the size and weight of your window sash.
- **Casement Hinges:** You will need top and bottom hinges designed for casement windows.
- **Locking Mechanism:** A new lock for the casement window.
- **Screen Frame Kit:** To build a custom-sized screen.
- **Screen Mesh:** The screen material.
- **Wood for frame modifications (if necessary):** You may need to add or modify wood to accommodate the new hardware.
- **Wood Filler, Screws, Fasteners, and Weatherstripping.**

## Step-by-Step Guide

1.  **Remove the Window Sash and Existing Hardware:** Carefully remove the window sash from the frame. Remove all old hardware (hinges, locks, etc.) from both the sash and the frame.

2.  **Prepare the Window and Frame:**
    - Fill old screw holes with wood filler and sand smooth.
    - The most critical part of the preparation is creating a space for the casement operator. This will likely require careful chiseling and routing on the window sill and bottom of the sash.
    - Ensure the window sash is in good structural condition. Repair any rot or damage.

3.  **Install New Hinges:**
    - Install the four-bar hinges on the top and bottom of the window sash and frame.
    - The hinges should be installed so that the window opens outwards.
    - Follow the manufacturer's instructions for the specific hinges you have purchased.

4.  **Install the Crank Operator:**
    - The operator is typically installed on the window sill, orthogonal (perpendicular) to the window.
    - Position the operator on the sill according to the manufacturer's instructions. This usually involves aligning it with the center of the window opening.
    - You will need to route a channel in the sill for the operator's arm to move freely.
    - Attach the operator to the sill with screws.
    - Attach the operator's arm to the window sash using the provided bracket.

5.  **Install the Locking Mechanism:** Install the new casement lock on the side of the sash and frame.

6.  **Build and Install the Screen:**
    - Build a custom screen frame to fit the interior of your window opening.
    - Install the screen mesh into the frame.
    - The screen can be installed with clips or other hardware to be easily removable for cleaning.

7.  **Install Weatherstripping:** Add new weatherstripping around the window sash to improve energy efficiency.

## Important Considerations

- **Hardware Selection:** The most challenging part of this project is selecting the correct hardware. You will need to find a casement operator and hinges that are rated for the size and weight of your window. Take careful measurements of your window before purchasing hardware.
- **Window Condition:** This project should only be attempted on a window that is in excellent structural condition.
- **Complexity:** This is an advanced DIY project. If you are not comfortable with woodworking and joinery, it is best to hire a professional.
