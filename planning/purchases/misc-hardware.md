# Miscellaneous Hardware Purchases

This document tracks miscellaneous hardware needed for repairs.

## Side French Door Threshold

The threshold for the side French door needs to be replaced. The correct depth depends on the width of the door jamb, which is determined by the wall's construction (either 2x4 or 2x6 framing).

**To Do:** Measure the width of the door jamb from the interior edge to the exterior edge to determine the required threshold depth.

*   If your wall is built with **2x4 studs**, the jamb will be **4 9/16 inches** wide. You need the **4 1/2 inch** threshold.
*   If your wall is built with **2x6 studs**, the jamb will be **6 9/16 inches** wide. You need the **5 5/8 inch** threshold.
